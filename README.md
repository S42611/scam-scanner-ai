# 🛡️ Scam Scanner AI

An AI-powered web application designed to help users identify suspicious messages, screenshots, and links and understand potential scam risks.

## 🚀 Live Demo

https://superb-cobbler-427f95.netlify.app

## ✨ Key Features

- 🔍 Scam message detection
- 📸 Screenshot-based scam analysis
- 🔗 Suspicious link checking
- 🧠 Explainable scam risk analysis
- 🛡️ Safety recommendations
- 🌐 Simple and user-friendly interface

## 💡 Problem

Online scams often look like genuine messages, making it difficult for users to identify threats quickly.

## 💡 Solution

Scam Scanner AI analyzes suspicious content and presents the detected warning signs in a simple and understandable way, helping users make safer decisions.

## 🛠️ Technology

- HTML
- CSS
- JavaScript
- AI-assisted analysis
- Netlify

## 🎯 Innovation

The project focuses not only on detecting suspicious content but also on **explaining why it may be risky**, making scam awareness easier for everyday users.
